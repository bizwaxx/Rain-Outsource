Privacy

Draft dated October 20, 2026. Applies to the Rain-Outsource API and MCP server at rainout-agent-source.vercel.app and the docs at bizwaxx.github.io/Rain-Outsource.

The short version

You don't need an account, a key or an email to use Rain-Outsource. We don't sell data, and we don't build profiles of people. We keep counts of how much the service is used, not who used it.

What we keep

  • Usage counts. Totals like "how many calls each tool or endpoint got per day," kept for about 400 days. To estimate how many different clients used the service on a day, the network address is turned into a keyed one-way hash (HMAC-SHA256 with a secret key that changes every day) and added to an approximate counter (a HyperLogLog) that keeps only the total. We also keep one record of the very first outside request: its time, the endpoint or tool, a broad client type (like "curl") and the country our host reports. No raw IP address or User-Agent is stored.
  • Rainout reports you choose to share. If you or your agent send a report (for example "cancelled" at a field), we store the field, the status, the game time, the time of the report and any short note you add (up to 280 characters). Reports are public: anyone can read recent ones at /v1/reports. They are anonymous and are deleted automatically after 24 hours. Please don't put names or contact details in the note.
  • Rate limits. To stop spam on rainout reports, the sender's network address is turned into a keyed one-way hash (HMAC-SHA256 with a secret key that changes every day) and used as an hourly counter key. It expires within an hour and is never written into the report. Without the secret key, nobody can work out an address from the hash by trying addresses. We hold the key, so during that hour we could check whether a particular address matches. We don't do that.
  • Weather cache. We save weather forecasts for places so we don't ask the weather services the same thing over and over. This is weather data, not data about you.

What we send to others

  • To answer a question, we send the place or coordinates (never your identity) to weather and map services: the US National Weather Service, NOAA and Open-Meteo (forecasts and place-name search).
  • If you give us a schedule or event link, we fetch that link to read the games on it.
  • On the switch page, the field list or schedule you paste is sent to our API only to check it. It isn't saved. A shared board link holds only public field IDs. Browser notifications are created by your own browser, and we don't keep a list of who turned them on.
  • We read public official status pages from leagues, venues and tracks.

Hosting

The service runs on Vercel, and its shared storage is Upstash. Like any web host, Vercel may keep short-lived technical request logs (which can include IP addresses) under its own privacy policy. We use those logs only to fix problems, not to track people. The docs site is hosted on GitHub Pages.

Cookies

The API and these pages don't set cookies or use ad trackers.

Calendars

Rain-Outsource never reads or writes your calendar. It gives your agent a ready-made event, and your agent should ask you before adding it.

Children

The service doesn't ask for personal information, and it isn't meant to collect any from anyone, including children.

Changes and contact

If this page changes, the update will be in the public GitHub history. Questions or a request about a report you sent? Open an issue at github.com/bizwaxx/Rain-Outsource/issues.
